# formula1-analysis-
Formula 1 data analysis dashboard (1950-2024, 2025) and machine learning (2025) using Python and Streamlit

🏎️ Formula 1 Data Analytics & Machine Learning

Project Overview

An end-to-end Formula 1 analytics and machine-learning project combining historical race analysis, driver and constructor performance evaluation, reliability analysis, predictive modelling, and interactive visualisation using Streamlit.

The project investigates historical Formula 1 performance and uses machine-learning models to forecast driver and constructor results. Predictions generated for the 2025 season are also compared against actual 2025 results to assess forecasting accuracy.

Project Objectives

- Analyse historical Formula 1 race and qualifying data.
- Evaluate driver and constructor performance across seasons.
- Investigate reliability, retirements and mechanical failures.
- Train and compare machine-learning models for race and season predictions.
- Forecast driver and constructor performance for the following season.
- Backtest predictions against historical seasons.
- Compare 2025 forecasts with actual 2025 results.
- Present findings through interactive Streamlit dashboards.

1. Historical Formula 1 Analysis

The exploratory data analysis investigates historical race results and qualifying performance.

Areas of analysis include:

- Driver victories and podium finishes.
- Constructor performance.
- Race and qualifying positions.
- Performance trends across seasons.
- Finishing positions and race outcomes.
- Reliability and retirement patterns.

The analysis pipeline generates processed datasets and visualisations for further investigation.

2. Reliability Analysis

The reliability component investigates race retirements and classifies failure-related outcomes.

The project distinguishes between different retirement categories, including mechanical failures and driver-related incidents where supported by the underlying status information.

Two classification models were developed:

- Logistic Regression
- Random Forest

Reliability Model Evaluation

Model| Accuracy| ROC-AUC
Logistic Regression| 82.02%| 0.5323
Random Forest| 85.27%| 0.5206

Although both models achieve relatively high accuracy, their ROC-AUC values are close to 0.5, indicating limited ability to distinguish between the evaluated classes.

These results demonstrate why model evaluation should consider more than accuracy alone.

3. Race Podium Prediction

Machine-learning classification models were trained to predict podium outcomes.

Models

- Logistic Regression
- Random Forest

Model Evaluation

Model| Accuracy| ROC-AUC
Logistic Regression| 83.04%| 0.8989
Random Forest| 81.20%| 0.9156

Logistic Regression achieved the higher classification accuracy, while Random Forest achieved the higher ROC-AUC.

The results illustrate the trade-offs between different evaluation metrics.

Driver Predictions

Constructor Predictions

Forecast targets include:

- Championship points
- Race wins
- Podium finishes
- Pole starts

Forecasting Approaches

Three forecasting approaches are compared:

1. Previous-season baseline
2. Ridge Regression
3. Random Forest Regression

The previous-season baseline provides a simple benchmark against which the machine-learning models can be evaluated.

5. Historical Backtesting

The forecasting models were evaluated using historical seasons from 2015 to 2024.

Evaluation metrics include:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Top-three prediction overlap

Example: Constructor Championship Points

Model| MAE| RMSE
Previous-season baseline| 79.19| 111.43
Ridge Regression| 82.80| 112.82
Random Forest| 95.33| 133.48

The previous-season baseline achieved the lowest MAE and RMSE for constructor championship points in this evaluation.

This highlights an important machine-learning finding: more complex models do not necessarily outperform a well-chosen baseline.

6. 2025 Prediction vs Reality

A dedicated Streamlit dashboard compares forecasts generated for the 2025 season with actual results.

Driver Analysis

The dashboard provides:

- Actual driver championship standings.
- Predicted versus actual race wins.
- Predicted versus actual podium finishes.
- Average finishing-position comparisons.
- Top-three performance comparisons.
- Driver-level prediction errors.

Constructor Analysis

The constructor dashboard includes:

- Actual constructor championship standings.
- Predicted versus actual championship points.
- Predicted versus actual race wins and podiums.
- Average finishing-position comparisons.
- Constructor performance rankings.
- Model prediction errors.

Model Evaluation

The dashboard evaluates Ridge Regression, Random Forest and the previous-season baseline against actual 2025 outcomes.

Metrics include:

- MAE
- RMSE
- Prediction errors by driver or constructor
- Top-three overlap for selected performance metrics

Note: The 2025 comparison is separate from historical backtesting. Its results should be interpreted after verifying dataset coverage and entity matching. Race-only results may not include sprint points, and the available 2025 files do not support qualifying-specific comparisons.

Installation and Setup

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY

Replace the placeholders with the repository's actual GitHub URL.

2. Create a virtual environment

python -m venv .venv

Activate it on Windows PowerShell:

.\.venv\Scripts\Activate.ps1

3. Install dependencies

pip install -r requirements.txt

4. Prepare the data

Place the required historical and 2025 CSV files in "data/raw/".

The processed datasets, prediction reports and trained models must also be available in their expected folders.

5. Run the historical analysis

python src/analyze_f1.py

6. Launch Streamlit

streamlit run app.py

Use the Streamlit sidebar to navigate between the analysis and prediction pages.

Key Findings

- Historical Formula 1 data can be used to investigate driver, constructor and reliability performance.
- Random Forest achieved a podium-prediction ROC-AUC of approximately 0.916.
- Logistic Regression achieved podium-classification accuracy of approximately 83.04%.
- Reliability models demonstrated that high accuracy does not always indicate strong predictive discrimination.
- The previous-season baseline outperformed Ridge Regression and Random Forest for constructor championship points in the reported historical evaluation.
- The 2025 comparison dashboard provides an additional opportunity to evaluate forecasting performance against actual season results.

Limitations

- Formula 1 regulations, driver transfers and team development can affect the accuracy of season forecasts.
- Models trained on historical relationships may not capture unexpected changes in team performance.
- Driver and constructor naming conventions require consistent mapping across datasets.
- Race-result data may not capture every source of championship points.
- Prediction rankings based on wins, podiums or average finishes are not equivalent to official championship rankings.
- Forecast accuracy should be assessed against a simple baseline and across multiple seasons.
